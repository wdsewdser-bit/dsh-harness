2. **摘要形态的条目在用到时补全文。** 回执现在记住哪些条目只给过摘要。条目变成“正在用”时，下一次交付带上全文。补发不是必需项：装不下就不发，不会产生欠项，也不会拒绝回合。

## 过程中修掉的一个错误

第一版实现把状态为 `completed` 的任务一律算作已结束。这个系统里任务一提交验收状态就是 `completed`，阶段才是 `verifier-review`，所以最该留全文的 t12 反而被排到最先压。离线核对发现了这一点，单测没有发现，因为测试数据是照着同一个错误理解写的。改成只有阶段为已验收、已取消、已过期，或状态为已删除、已取消才算结束，并补了对应的测试。
