# 观察页

"观察页"指 Team 面板本身：它是团队状态的只读视图，用来回答"团队现在在干什么、卡在哪、有没有要人处理的事"。数据全部来自 `packages/projections` 的只读投影，面板不持有数据库句柄、不写任何状态。

## 页面结构（v3，M6 之后）

| 位置 | 内容 |
|---|---|
| 顶部标题行 | 当前会话所属的团队；未开团队模式的会话不显示团队数据 |
| 中栏三个子页 | **现在**（默认）：进度条（分母是任务数）、最要紧的事、成员/任务摘要；**成员**：成员表（状态、任务、上下文占用、等待）；**记录**：按时间倒序的事件流 |
| 右栏检查器 | 选中对象（成员、任务、消息、提议、未知操作）的小节详情，纯只读 |
| 说明行 | 无法操作的原因（例如冻结期间不能确认停止），用人话写清楚下一步 |

信息呈现规则：内部 ID、字段名、状态机名称默认折叠；状态色有唯一含义（绿色只给"已验收"）。

## 离线看（不连 provider）

```bash
node verification/browser/serve.fixture.mjs [--port N] [--home DIR]
```

它启动 DSH web 宿主，只多挂一个 Team UI 插件，**mock 模式**：没有投影服务端口、没有 provider 凭据、不会发请求。输出里会给一个带 token 的登录 URL，打开即是带 17 名成员夹具的面板。`npm run test:browser` 用的就是它。

## 真实数据从哪来

面板只走 HTTP，端点由 `packages/projections/http.mjs` 提供：

| 端点 | 用途 |
|---|---|
| `GET /team/projection/snapshot` | 整页快照（首帧） |
| `GET /team/projection/stream` | SSE 增量；游标越界返回 `RESYNC_REQUIRED`，客户端重新同步 |
| `GET /team/projection/activity` | 记录页分页（首次/更旧/失败、按来源与团队筛选） |
| `GET /team/binding` | 当前会话与团队的绑定信息 |
| `POST /team/commands` | 唯一写入口（命令网关），面板只发命令、不直接改状态 |

## 看什么算"出问题了"

- 标题行/说明行出现"等很久没动"：多半是 effect 被 `deferred`（维护中的成员），不是失败。
- 成员状态是 running 但很久没产出：看它的任务与上下文占用，再看记录页最后一条事件。
- 出现"需要你处理"：`unknownEffects` 或冻结中的完成裁决。冻结期间确认停止会被拒绝是**预期行为**（内部设计记录 0013）。
- 连接健康点：蓝色表示连接正常（绿色只给"已验收"，不要拿来表达连接）。
