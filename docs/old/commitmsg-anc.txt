docs: 新条款「某提交的父在目标分支上不蕴含该提交在目标分支上；是否已并入只能读祖先判定」

- 实证：组长把「返工提交的父 9635ebb 在 main」误推为「返工提交本身在 main」，据此写下复跑协议；实测 git branch --contains 只有该成员的成员分支 ⇒ 协议在单棵树上物理不可完成。
- 纪律：「父在」不蕴含「自己在」；「是否已并入」只能读祖先判定（--is-ancestor / branch --contains），不得由「父在哪」推导。
- 族属：本条是肯定性方向的镜像（既有条款管否定性与状态性主张）；共同解法 = 主张的对象必须与读数的对象一致。
- 正面形态：组长发现协议物理不可完成时没有硬跑，而是停下、给出拓扑实测与三个选项并请裁定。
