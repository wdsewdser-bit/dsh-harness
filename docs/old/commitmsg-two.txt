docs: 两条通则入册（解除类裁定必须先自核决定性证据；复验必须换权威）

- 约束的「解除」比「施加」危险：施加只会让人停手，解除会让人动手 ⇒ 解除类裁定（放宽 scope / 换归属 / 解除禁令）必须先自核决定性证据再执行。族属「执行他人裁定时未自核前提」——比「转述未核」更重：它把未核的裁定变成了对成员的实际派工。
- 复验必须换权威：重读同一来源只是复述，不是复核；对自称未验证的文档做二次阅读更不构成复核。归属/身份类判定的第一顺位是工件自身的自述（README 首行 / 源码首行 / USAGE 串）。
- 更正 tier 0 自己的记录：不是「执行方没抢跑」才没事，而是成员在被 interrupt 时仍在 running 但尚未写入。
