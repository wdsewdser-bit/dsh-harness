
**20. 从混合输出里取标识符，必须按「该标识符的形态」取，不得按行位置取。** 实测：我用 `split("\n")[1]` 从 `git commit` 的混合输出取 sha ⇒ 取到 ` 2 files changed, 27 insertions(+), 1 deletion(-)`，**它被写进了 `task-21` 的 `commit_sha` 与证据行**；真值在**第 3 行**（40 位 hex）。⇒ 正确做法 = 按**形态**匹配（`\b[0-9a-f]{40}\b`），或**单独调用** `git rev-parse HEAD`（纯输出）。与「先过滤再断言」「按内容不按位置」同族。**已用 `bind_fix` 更正。**
