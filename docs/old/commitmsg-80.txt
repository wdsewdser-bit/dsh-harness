task-80: §5.14-44 三次收窄 —— 类判据必须自带「形态判定」+ 排除项 (i) 的可机检谓词

- 排除项 (i) 可机检化：命中前后 ±120 字符内出现 反例/文档化/禁止/不递归/静默 之一
  （= citation_integrity 的 QUOTE_MARKER / QUOTE_WINDOW=120 的类比物）；(ii) 语法可判：token 含 < > * 或反引号。
- 关键补充：类谓词必须自带「形态判定」——「排除后为空」只适用于被点名的那个类（本例目录形态），
  不适用于全部 Select-String -Path 出现，否则判据永不可满足（合法的单文件读数不是缺陷）。
  实测：目录形态这一类 total=1 / excluded=1 / after=0；存活的 32 处全是单文件形态，合法不得排除。
- 完整形态 = 谓词 + 形态判定 + 排除项 + 标记集 + 窗口 + 三个数（total/excluded/after），结果标「排除后的出现次数」。
- 实测：docs/groups/world/*.md 3 文件 @ 2026-09-27T21:05Z ⇒ 65/41/1/23/10/32；
  与 verifier 在 49091d2 的独立读数 65/41/1/23 逐值相符。61(21:00Z) vs 65(21:05Z) 不是矛盾而是时刻与内容不同。
