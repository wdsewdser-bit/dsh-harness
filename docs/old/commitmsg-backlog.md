docs: 落盘积压条款（t33 并入后的窗口）

- 读数五轴 + 两问：谓词/域/大小写/revision/仪器；且候选轴须给不同答案、域须排除断言句自身。
- 引用一个值必须从产生它的那次调用取（从未存在过的读数，比轴未具名更重）。
- 以某读数为裁决依据前，必须先用第二个独立仪器在同一输入上对照。
- 任何取数步骤失败必须中止；提交前必须检查退出码。
- team_merge 不执行快进 ⇒ 能快进就快进必须指定非 team_merge 的机制。
- 仓级修复 != 每检出修复；核内容一律用 git cat-file blob。
- 空集与确实没有不可区分 ⇒ 假阴性仪器必须报错或标注过滤形态。
