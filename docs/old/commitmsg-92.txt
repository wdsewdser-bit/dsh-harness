task-92: 收编三条 —— 红数不是签名（panic 位点才是）/ 「退出码 0 + 空输出」不是读数 / task-91 纪律二的首个正例

- 红数不是签名：2 红 = M1（源码中态）；1 红且 panic 落在 spawn 位点 = M2（修前 12/12 是 spawn 失败，非 stdout 比对失败）。
  判据的可归因性要求「红数 + panic/失败位点」成对给出。
- 「退出码 0 + 空输出」不是读数：PowerShell 里 H 是 Get-History 的别名，解析优先级 Alias > Function ⇒ 自定义函数被压过，
  三次哈希静默返回空而 exit 0。⇒ 单字母名规则第二实例（对象=函数名）+ 机制；仪器必须带正例对照自证。
- task-91 纪律二的首个正例：t74 执行者遇到 scope 外条款时先找域内替代（README 读数口径节 + evidence 行），未申请扩权。
