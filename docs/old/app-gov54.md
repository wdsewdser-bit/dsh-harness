**依赖集何时可以限定（2026-09-28 · lead-rig 的可判定准则 · tier 0 采纳）**
- **依赖集可枚举，当且仅当读数的依赖就是该检查的对象本身；一旦判定需要读别的文件，依赖集就是整个域。**
- **操作性问题 = 「这次判定会不会去读被检对象之外的文件？」** 实测支撑：
  · **rig harness 可限定**：`tools/rig-batch` + `tests/fixtures/rig-batch` **就是被测对象本身**（run 的主题）；
  · **门禁不可限定**：它的判定**要读别的文件** —— `errata.md` 的 `:196` 的 token 指向 `GOVERNANCE.md` 的 `:345`；`village.rs` 的 `:692` 指向 `mc-world/src/block.rs` 的 `:197-198`。

**错误类比：从一个情形推广规则之前，先证明两个情形的结构相同（2026-09-28 · lead-rig 第 6 次同类自纠 · tier 0 采纳）**
- 前五次是**「数字对、框错」**（域 / 单位 / 依赖集各少测一半）；**第六次不是框错，是错误类比** —— 把一条**在结构不同的情形下正确**的规则搬了过来（rig harness 的「绑定树」作用域 ⇒ 门禁的依赖集）。
- ⇒ 教训：**「从一个情形推广一条规则之前，先证明两个情形的结构相同。」** ⇒ **这比「框」更一般，因为它连「框」都可以是照搬来的。**
