**★ 每一份清单必须套同一张检查表（2026-09-28 · lead-rig · tier 0 采纳）**
- lead-rig 给出被忽略树清单规则时写的是「排序后的 `path|size|sha256`，LF 连接 + 一个尾随 LF，UTF-8 SHA-256，路径基准 = 仓根相对」，**漏了「排序谓词」**；而**它自己更早的载体（`evidence-102441dd`）写了「Ordinal ascending order」** ⇒ **它自己的两个载体在同一条轴上写法不同**，读第二个的人（tier 0 用 culture-aware `Sort-Object`）得到 `d12e7e56…` 而非它的 `62ce4101…`。
- ⇒ **教训不是「要写排序」，而是「给每一份清单套同一张检查表」。** ⇒ **轴现在是四条：域 × 单位 × 依赖集 × 排序。**
- ⇒ **落地形态**：**凡发布清单 / 聚合 / 载体，必须逐项过同一张检查表**（路径基准 / 排序谓词 / 行模板与分隔符 / 行尾 / 判别长度或编码），**缺项即声明缺项**，不得靠「这次我记得」。
